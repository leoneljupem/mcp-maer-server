───────────────────────────────────────────────────────────────────────
  PROGRAMAS / SCRIPTS PRINCIPALES
───────────────────────────────────────────────────────────────────────

1. maer_iniciar.sh
   ─────────────────
   Script de inicio para macOS/Linux. Menú interactivo que permite
   elegir entre lanzador gráfico, consola, servidor con ngrok o solo
   el backend. Detecta automáticamente el entorno Python correcto
   (prioriza maer_env con todas las dependencias ML instaladas).
   Muestra el estado de Ollama y Groq al arrancar.

   Uso:
     bash maer_iniciar.sh           # Menú interactivo
     bash maer_iniciar.sh gui       # Lanzador gráfico directo
     bash maer_iniciar.sh consola   # Consola IA
     bash maer_iniciar.sh ngrok     # Servidor + acceso desde celular
     bash maer_iniciar.sh server    # Solo backend FastAPI
     bash maer_iniciar.sh mcp       # Servidor MCP para Claude Desktop
     bash maer_iniciar.sh test      # Ejecutar todos los tests


2. lanzador_maer.py
   ──────────────────
   Interfaz gráfica (GUI) de control total de MAER. Permite iniciar el
   servidor en modo LOCAL (solo tu computadora) o EN LÍNEA (con túnel
   ngrok para acceso desde celular, tablet o extensión de Chrome).

   Funciones principales:
   • Botón "LOCALHOST"  → servidor privado en http://localhost:8765
   • Botón "EN LÍNEA"   → genera URL pública tipo https://abc123.ngrok.io
   • Log del sistema    → muestra mensajes del servidor en tiempo real
   • Chat integrado     → conversa con MAER sin abrir el navegador
   • Herramientas:
     - Analizador HTML tipo F12 (inspeccionar el dashboard web)
     - Exportar PDF del expediente
     - Verificar dependencias del sistema
     - Analizar carpeta de documentos
     - Selector de modelo Ollama (elegir qwen3.5, deepseek-r1, etc.)
     - Panel diagnóstico
     - Código QR de la URL pública (para compartir con celular)
   • Detecta Ollama y Groq automáticamente al iniciar
   • Muestra todos los modelos Ollama instalados con tamaño y parámetros

   Requisitos: pip install requests pyngrok (pillow para QR)


3. maer_consola.py
   ─────────────────
   Consola IA avanzada en la terminal. Interfaz de línea de comandos
   con colores, autocompletado (Tab) e historial (flechas ↑↓).

   Comandos principales:
     chat  <pregunta>   → Pregunta a MAER IA sobre IMSS/pensiones
     analizar <archivo> → OCR + análisis de documentos (PDF, imagen, Word)
     carpeta  <ruta>    → Analiza TODOS los archivos de una carpeta
     aprender <ruta>    → Aprende e indexa todos los archivos permanentemente
     vigilar  <ruta>    → Monitorea cambios en carpeta en tiempo real
     buscar   <término> → Busca en todo el conocimiento aprendido
     reporte  [html|pdf]→ Genera informe completo del expediente
     tablas   <pdf>     → Extrae tablas de un PDF (estados de cuenta IMSS)
     deps               → Verifica qué dependencias están instaladas
     estado             → Estado del servidor y conocimiento indexado
     historial          → Últimas 20 conversaciones
     ayuda              → Mostrar todos los comandos disponibles

   También puedes escribir cualquier pregunta directamente sin comandos.


4. iniciar_maer_ngrok.py
   ─────────────────────
   Script para acceso remoto. Inicia el servidor backend y crea un
   túnel ngrok que genera una URL pública accesible desde internet.
   Útil para acceder desde el celular o compartir con familiares.

   Configura en .env:
     NGROK_AUTHTOKEN=tu_token   → sesión ilimitada (token gratis en ngrok.com)
     (sin token: sesión de 2 horas)

   Uso:
     python iniciar_maer_ngrok.py
     → imprime la URL pública (tipo https://abc123.ngrok.io)


5. detectar_ollama.py
   ────────────────────
   Herramienta de diagnóstico para Ollama. Detecta si Ollama está
   instalado, si el servidor está activo, lista todos los modelos
   descargados con su tamaño y recomienda el mejor para MAER.

   Uso:
     python detectar_ollama.py          → información básica
     python detectar_ollama.py --test   → prueba cada modelo con pregunta
     python detectar_ollama.py --pull   → descargar modelo recomendado


6. maer_guardian.py
   ──────────────────
   Verificador de integridad del sistema MAER. Compara checksums de
   todos los archivos críticos (JS, CSS, Python, HTML) contra un
   manifiesto guardado. Detecta archivos modificados, faltantes o
   corrompidos. También se puede ejecutar en modo continuo para
   monitoreo automático.

   Uso:
     python maer_guardian.py            → verificar integridad completa
     python maer_guardian.py --init     → crear manifiestos (primera vez)
     python maer_guardian.py --reporte  → ver último reporte guardado
     python maer_guardian.py --watch    → modo continuo (cada hora)


7. maer_tester.py
   ─────────────────
   Suite de pruebas del sistema completo. Verifica que todos los
   módulos Python importan correctamente, que el servidor responde,
   que OCR funciona, y que la cascada LLM está operativa.

   Uso:
     python maer_tester.py


8. index.mjs (Servidor MCP)
   ──────────────────────────
   Servidor MCP (Model Context Protocol) que conecta MAER con
   Claude Desktop. Expone todas las herramientas de MAER como
   funciones que Claude puede llamar directamente en el chat.

   Herramientas disponibles para Claude:
   • analizar_archivo      → OCR + extracción de texto de cualquier archivo
   • buscar_archivos       → buscar por nombre, contenido o tipo
   • detectar_ids_mexicanos→ extraer CURP, NSS, RFC de documentos
   • llm_chat              → chat con IA (Ollama/Groq/OpenAI)
   • verificar_curp_renapo → validar CURP contra base RENAPO
   • expediente_imss       → analizar carpeta con documentos IMSS
   • generar_carta         → redactar carta formal para IMSS
   • extraer_tablas        → tablas de PDFs (estados de cuenta IMSS)
   • analizar_imagen       → OCR + reconocimiento facial (DeepFace)

   Uso:
     node index.mjs   → inicia servidor MCP
     (Claude Desktop lo llama automáticamente según configuración)

   Configuración en Claude Desktop:
     ~/Library/Application Support/Claude/claude_desktop_config.json:
     { "mcpServers": { "maer": {
         "command": "node",
         "args": ["/Users/houssenm/mcp-maer-server/index.mjs"]
     }}}

───────────────────────────────────────────────────────────────────────
  MOTORES DE IA (CASCADA LLM)
───────────────────────────────────────────────────────────────────────

MAER usa una cascada de motores en este orden de prioridad:

  1. Ollama (local)    → IA privada, sin internet, sin costo.
                         Modelos recomendados (instalados):
                         • qwen3.5:latest   (6.6 GB) ⭐ preferido
                         • deepseek-r1:8b   (5.2 GB)
                         • gemma3:latest    (3.3 GB)
                         • deepseek-ocr     (6.7 GB)
                         Activar: ollama serve

  2. Groq (nube)       → IA en la nube, GRATIS con registro.
                         30 peticiones/minuto, sin límite diario.
                         Modelo: llama-3.3-70b-versatile
                         Activar: agrega GROQ_API_KEY=gsk_... en .env
                         Registro: console.groq.com

  3. OpenAI            → GPT-4o-mini u otros modelos de OpenAI.
                         Activar: agrega OPENAI_API_KEY en .env

  4. Diccionario local → Siempre disponible, sin internet.
                         Base de conocimiento IMSS: Ley 73, Ley 97,
                         semanas cotizadas, AFORE, CURP, NSS, recursos.

TODOS los motores responden en español con identidad MAER.


───────────────────────────────────────────────────────────────────────
  MÓDULOS PYTHON BACKEND
───────────────────────────────────────────────────────────────────────

maer_backend/maer_files.py
   Módulo principal con todas las acciones del servidor MCP:
   • Validación CURP, NSS, RFC
   • Análisis de expedientes IMSS
   • Cascada LLM: Ollama → Groq → OpenAI → diccionario local
   • Generación de cartas y reportes
   • Búsqueda e indexación de archivos

maer_backend/ocr_engine.py
   Motor OCR multi-proveedor:
   • Tesseract (rápido, texto impreso)
   • EasyOCR   (documentos escaneados, mejor calidad)
   • PaddleOCR (PDFs complejos, tablas)
   Caché automático por hash del archivo para no re-procesar.

maer_backend/maer_ollama.py
   Gestión inteligente de Ollama:
   • Detección automática del binario en múltiples rutas
   • Lista y elige el mejor modelo según preferencia
   • Arranque automático del servidor si está instalado
   • Prompt de sistema en español (identidad MAER)

maer_backend/llm_engine.py
   Motor GGUF local con llama-cpp-python. Carga modelos .gguf
   directamente sin necesidad de Ollama. Alternativa offline.

maer_backend/nlp_engine.py
   Procesamiento de texto con spaCy en español:
   • Extracción de entidades (nombres, fechas, NSS)
   • Segmentación de oraciones
   • Limpieza de texto OCR

maer_backend/table_extractor.py
   Extracción de tablas de PDFs:
   • pdfplumber para tablas simples
   • camelot-py para tablas complejas
   • tabula-py para estados de cuenta IMSS

maer_backend/image_analyzer.py
   Análisis de imágenes:
   • OCR de fotografías
   • Reconocimiento facial con DeepFace
   • Hash perceptual para detectar duplicados (imagehash)

maer_backend/maer_core/analyzer.py    → Análisis profundo de documentos
maer_backend/maer_core/fixer.py       → Corrección automática de CURP/NSS
maer_backend/maer_core/generator.py   → Generación de cartas para IMSS
