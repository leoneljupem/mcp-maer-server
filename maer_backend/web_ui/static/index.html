📱 Conectar Tasker (Android) con MAER

          

            Tasker puede enviar datos (SMS, ubicación, eventos) al servidor MAER desde tu Android.
            Sigue estos pasos con la app Tasker instalada.
          

          
          

            
1️⃣ URL del servidor MAER

            

              
              
            

            

            

              ⚠️ Para acceso desde Android en la misma red: la URL se detecta automáticamente con la IP de esta computadora.
              Para acceso remoto usa ngrok (npm run ngrok) — la URL pública se mostrará aquí.
            

          

          
          

            
2️⃣ Crear tarea en Tasker → Acción HTTP POST

            

              
Acción: HTTP Request (Plugin → HTTP Request)

              
Método: POST

              
URL: http://<IP_SERVIDOR>:8765/api/tasker-receive

              
Content-Type: application/json

              
Body:

              
{

                  "mensaje": "%SMSRB",

                  "fuente": "sms_entrante",

                  "dispositivo": "%DEVID",

                  "numero": "%SMSRF"

              }

              
            

          

          
          

            
3️⃣ Variables de Tasker más útiles

            

              
%SMSRBCuerpo del SMS recibido

              
%SMSRFNúmero del remitente

              
%DEVIDID del dispositivo

              
%LOCLatitud,Longitud GPS

              
%BATTNivel de batería (%)

              
%TIMEHora actual HH:MM

              
%DATEFecha actual

              
%WIFINombre de red Wi-Fi

            

          

          
          

            
4️⃣ Casos de uso sugeridos

            

              
📲 SMS de IMSS: perfil Tasker "SMS recibido" de número IMSS → envía a MAER

              
📍 Llegada IMSS: perfil Geofence en clínica → avisa a MAER para registrar visita

              
📅 Recordatorio: alarma diaria → consultar estado del expediente via chat MAER

              
🔔 Notificación: interceptar notif de app IMSS Digital → reenviar texto a MAER

            

          

        

        
        

          
          
        

      


      
      

        

          
          
        

        

          
Sin mensajes Tasker todavía. Configura Tasker con la URL del servidor.
